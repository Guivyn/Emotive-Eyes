# ESP32 Emotive Eyes — 技术文档

## 概述

ESP32 + ST7796 TFT（320×240）过程式生成的表情眼睛系统。纯 CPU 计算面部几何，无需预渲染资源文件。

核心算法移植自 Alastair Aitchison / playfultechnology 的 SH1106 OLED 版本，渲染方式改为基于浮点贝塞尔边界 + 扫描线填充的过程式管线。

## 硬件要求

| 组件 | 型号 |
|------|------|
| MCU | ESP32（ESP32-WROOM-32 系列） |
| 屏幕 | ST7796 SPI TFT (320×240) |
| 驱动库 | TFT_eSPI（通过 platformio.ini 构建开关配置） |
| 背光控制 | GPIO 27（低电平关，高电平开） |

### TFT_eSPI 配置要点

无需修改 `User_Setup.h`。本项目通过 `USER_SETUP_LOADED=1` 在
`platformio.ini` 的 `build_flags` 中直接配置：

- `ST7796_DRIVER`
- `TFT_CS`、`TFT_DC`、`TFT_RST`、`TFT_BL` 等引脚
- `SPI_FREQUENCY=80000000`（80MHz）
- `TFT_RGB_ORDER=TFT_BGR`

main.cpp 中仅调用 `tft.begin()`。

## 系统架构

### 渲染管线

每帧 Eye::Update() 按序执行以下 5 级变换，输出链式传递：

```
Transition → Transformation → Variation1 → Variation2 → Blink → FinalConfig
```

```
                   ┌──────────────────┐
  Transition ─────→│  Transition.Output│←──── Snapshot（转换起点）
                   └────────┬─────────┘
                            ↓
                   ┌──────────────────┐
  Transformation ─→│Transformation.Out│←── Destin（视线目标 + Scale）
                   └────────┬─────────┘
                            ↓
                   ┌──────────────────┐
  Variation1 ─────→│ Variation1.Output │←── Values（微表情参数）
                   └────────┬─────────┘
                            ↓
                   ┌──────────────────┐
  Variation2 ─────→│ Variation2.Output │←── Values（微表情参数）
                   └────────┬─────────┘
                            ↓
                   ┌──────────────────┐
  Blink ──────────→│  Blink.Output     │←── 眨眼（压缩高度 + 拉伸宽度）
                   └────────┬─────────┘
                            ↓
                    FinalConfig → EyeDrawer::Draw()
```

### 动画引擎

所有动画均继承自 AnimationBase，以 millis() 为时间基准，帧率无感知。

| 类 | 波形 | 用途 |
|----|------|------|
| RampAnimation | 0 → 1（线性，保持） | Transition、Transformation |
| TrapeziumAnimation | 0 → 1 → 0（梯形，单次） | 眨眼 |
| TrapeziumPulseAnimation | 0 → 1 → hold → 0 → hold（循环脉冲） | Variation 脉冲 |

### 状态组件

#### EyeTransition — 表情切换

当表情切换时：
1. TransitionTo() 将当前 Transition.Output 快照到 Snapshot
2. 设置 Destin 为目标表情配置
3. 启动 RampAnimation(500ms) 从 Snapshot → Destin 做线性插值

所有字段（Offset、Height、Width、Slope、Radius、Inverse 系列）均参与插值。

关键：使用 Snapshot 作为固定起点，而非原地修改 Config（避免帧率依赖漂移）。

#### EyeTransformation — 视线方向

LookAssistant 每 1.5~3.5 秒随机选择新的视线方向 (x, y)：

- MoveX = -20 × x（左右偏移）
- MoveY = 20 × y（上下偏移）
- ScaleY = (1 - 0.2×|x|) × (1 - 0.4×|y|)（透视缩放）
- ScaleX = 1.0（不缩放宽度）

SetDestin() 将当前 Output 保存到 Origin，再设置新 Destin 为视线目标，RampAnimation(200ms) 从 Origin → Destin 平滑过渡。

关键：Origin 快照确保视线变化时眼睛不会跳回 OffsetX=0 的"中间"位置。

#### EyeVariation — 微表情

每个表情可设置 Variation Values（如 Normal 的 Height ±3），通过 TrapeziumPulseAnimation 产生呼吸/脉冲效果。

当表情切换时，StartFadeOut() 捕获当前实际偏移量到 FadeValues，在 150ms 内渐出至零，避免"闪回"。

#### EyeBlink — 眨眼

BlinkAssistant 每 2~5 秒触发一次眨眼。TrapeziumAnimation(100ms→50ms→100ms) 将眼睛高度压缩至接近零再恢复。

### 表情系统

19 种预设表情，每种定义完整的 EyeConfig：

| 表情 | 特征参数 |
|------|---------|
| Normal | Height=50, Radius_Top/Bottom=10 |
| Angry | Height=25, Slope_Top=0.3, Radius_Bottom=15 |
| Happy | Height=12, Radius_Top=12 |
| Sad | Height=19, Slope_Top=-0.5, Radius_Bottom=12 |
| Surprised | Height=56, Radius_Top/Bottom=20 |
| Sleepy | Height=18, Slope_Top/Bottom=-0.5 |

每种表情还可附带 Variation 参数使眼睛产生自然微动。

### 行为系统

#### 启动阶段

| 时间 | 事件 |
|------|------|
| 0ms | Face 创建并直接显示闭眼画面 |
| 500ms | 显示 Normal 表情 |
| 5000ms | 开启随机视线（LookAssistant） |
| 8000ms | 开启随机眨眼 + 随机表情切换 |

#### 表情权重

FaceBehavior 以权重随机选择下一个表情：

| 表情 | 权重 |
|------|------|
| Normal | 4 |
| Angry / Glee / Happy / Surprised | 2 |
| 其余 | 1（Sleepy 为 2） |

定时器周期 4 秒，Transition 动画 500ms，每次切换后有 3.5s 停留观察。

### 几何渲染：EyeDrawer

EyeDrawer::GenerateBoundary() 根据 EyeConfig 生成眼睛边界多边形：

1. 计算 4 个内角坐标（TL/TR/BL/BR），考虑 Slope 引起的偏移
2. 在 4 个角位置产生圆弧段（每 15° 一个采样点），共约 24+ 个边界点
3. 如果圆角半径超过眼睛总高度，按比例缩小

EyeDrawer::RasterizePolygon() 对多边形进行扫描线填充：
- 计算 Y 方向边界范围
- 每行求与多边形边界的 X 交点
- 排序后配对绘制水平线段

渲染器优先申请一块 TFT_eSprite 全屏缓冲（320×240，约 150KB），每帧将两只眼睛和睡眠符号完整绘制后一次性推送。对于没有足够连续 RAM 的 ESP32，自动退回一个 160×240 全高分块并分两次推送左右半屏；每个分块都覆盖完整背景和场景，因此不会因缓冲申请失败而白屏，也不会留下局部旧帧。

## 触控交互

板载 XPT2046 触摸屏与 TFT 共用同一 SPI 总线，仅片选独立。实际接线经启动扫描确认：

| 信号 | GPIO | 备注 |
|------|------|------|
| TOUCH_CS   | GPIO33 | 片选 |
| TOUCH_CLK  | GPIO14 | 与 TFT_SCLK 共用 |
| TOUCH_MOSI | GPIO13 | 与 TFT_MOSI 共用 |
| TOUCH_MISO | GPIO12 | 与 TFT_MISO 共用 |

驱动使用 TFT_eSPI 内置 XPT2046 读取（`TOUCH_CS` + 共享 SPI），按 Z 轴压力判断按下，不依赖 IRQ 引脚。引脚定义写入 `platformio.ini` 的 `build_flags`，方便按实际接线调整。

### 连续点按 → 愤怒表情

默认配置下：

1. 连续点按屏幕 3 次，且相邻点击间隔不超过 300ms（`DOUBLE_TAP_WINDOW_MS`）
2. 触发 Angry 表情（仅眼睛变化，无额外 UI 覆盖）
3. 再次三连点可随时重新触发

按压力度阈值默认 `TOUCH_PRESSURE_THRESHOLD = 350`，不同面板可能需要微调；每个点按需完成一次按下→松开，长按不会重复计数。

## 电源管理（V1.0）

面向 3.7V / 700mAh 电池供电，按“桌面 AI 宠物”体验设计，避免频繁黑屏打断陪伴感。当前实现纯软件部分，全部可通过 `platformio.ini` 的构建开关控制。

### 运行状态

| 状态 | 进入条件（距上次交互） | 背光 | 刷新率 | 表情行为 |
|------|------------------------|------|--------|----------|
| ACTIVE | 0-60 秒 | 100% | 25ms（40fps） | 完整动画 + 随机表情 |
| RELAX | 60 秒 | 50% | 33ms（30fps） | 固定表情、慢速视线、眨眼变慢 |
| IDLE | 3 分钟 | 25% | 41ms（约24fps） | 固定 Normal、表情/视线回原点，无呼吸微动，偶眨眼 |
| SLEEP | 5 分钟 | 0% | 不渲染，50ms 触摸轮询 | Sleepy 闭眼静态画面 |

任意触摸都会把设备带回 ACTIVE，并重置空闲计时。
CPU 频率随状态调整：ACTIVE 240MHz、RELAX 160MHz、IDLE 80MHz、SLEEP 80MHz；进入 SLEEP 时发送 `DISPOFF (0x28)`，唤醒时发送 `DISPON (0x29)` 降低面板功耗。

背光使用 Gamma 2.2 感知曲线（`PWM = 255 × (level/100)^2.2`），状态切换时以 20ms/档平滑渐变，避免亮度跳变，低档位更省电。

渲染采用事件驱动：`Face::Update()` 通过 `Eye::NeedsRedraw()` 判断眨眼、表情切换、视线、微表情等动画是否在变化，只有画面变化时才推 sprite；RELAX/IDLE 进入时清除呼吸微表情，静止期间 SPI 不工作。

自动调光和电池/充电检测均已移除。该板光敏硬件接在 GPIO34，但动态范围偏窄、易误调暗，暂不使用。

### 触摸手势

| 手势 | 动作 |
|------|------|
| 单击 | 眼睛快速眨眼作为反馈，并重置空闲计时 |
| 双击（300ms 内） | 回到 Normal 表情 |
| 三连击（相邻点击间隔不超过 300ms） | 触发 Angry 表情 |
| 长按（2s） | 回到 Normal 表情 |
| 上滑 | 撒娇（Coquette） |
| 下滑 | 进入睡眠模式（Sleepy + Zzz）并切到低功耗 IDLE，再次触摸唤醒 |

### 温度保护与统计

- `POWER_TEMP_PROTECT_ENABLED=1`：芯片温度 ≥70°C 强制降入 IDLE，≥80°C 强制 SLEEP，每 5 秒采样一次；
- 每 30 秒串口输出 `[STATS]`：当前状态、背光档位、帧间隔、芯片温度；
- RELAX 状态下每 20-50 秒随机打一次“哈欠”（短暂 Sleepy 后回 Normal）；
- 开机直接显示闭眼，约 500ms 后睁眼醒来的过渡；
- 主循环日志改为每 5 秒一次，不再随帧数输出。

### 模块与构建开关

| 文件 | 职责 |
|------|------|
| `src/PowerManager.h/.cpp` | 状态机、背光 PWM、温度保护、LightSleep 入口 |
| `src/FacePower.h` | 表情层与电源层之间的解耦接口 |

校准文件采用 `CalibrationCodec::Record`（魔数、版本、offset、range、FNV-1a 校验和），写入临时文件成功后再原子替换正式文件，并兼容旧版 8 字节格式。
默认启动不会自动格式化 LittleFS；维护时可显式发送 `fs-init`，仅在普通挂载失败时格式化并重新挂载（该操作可能清除 LittleFS 内容）。

`platformio.ini` 中的开关：

| 开关 | 默认 | 说明 |
|------|------|------|
| `POWER_LIGHT_SLEEP_ENABLED` | 0 | GPIO36 触摸 IRQ 补 10kΩ 上拉后改为 1 |
| `POWER_TEMP_PROTECT_ENABLED` | 1 | 芯片温度保护 |
| `SERIAL_DEBUG_ENABLED` | 0 | 发布版关闭串口调试；调试时改为 1 |

## 已知问题与修复记录

### 修复 1：白屏（Input→Output 链断裂）

Transition 完成后 Active = false，但 Transformation 仍在读取 Transition.Output。早期版本 Transformation 的 Destin 默认全零，导致输出被清零。修复：TransitionTo() 同步设置 Destin + Sync() 初始化。

### 修复 2：表情切换"闪回"

ClearVariations() 瞬间清零 Variation Values → 眼睛高度跳变。修复：StartFadeOut() 用 150ms 渐出旧偏移量。

### 修复 3：周期性"闪回中间"

LookAssistant 每 1.5~3.5s 变换视线方向，Transformation 的 SetDestin() 未保存当前输出状态。restart 后的首帧回到 Input→OffsetX（表情默认偏移量，通常为 0），表现为眼睛"跳回中间"。修复：SetDestin() 将当前 Output 保存到 Origin，Apply 从 Origin → Destin 插值。

### 修复 4：启动闪随机形状

ChainOperators() 中 Transition.Output = Config 将未初始化的 Config （堆垃圾）复制到 Transition.Output。首次 Transition 以垃圾值作 Snapshot。修复：删除该行，Transition.Output 从全零开始。

## 编译与烧录

1. 安装 [PlatformIO](https://platformio.org/)（VS Code 扩展 或 CLI）
