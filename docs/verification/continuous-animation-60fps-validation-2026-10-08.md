# 连续动画 60fps 验证记录

> 历史验证记录 · 2026-10-08。本报告中的临时性能环境已归并；当前仅保留 `esp32dev_expression_test` 作为循环表情测试固件，旧环境名不再可构建。结果是程序帧计时，不是面板物理刷新率；当前配置见[技术文档](../技术文档.md)。

## 状态

本记录是**短时连续负载结果**，不是长时间稳定性结论。计划中的长时间运行按用户要求提前停止。

## 测试配置

- 固件环境：`esp32dev_always_on_perf60_continuous`
- 标称帧间隔：16ms，等效目标约 62.5fps，作为 60fps 压力测试
- 动画：每 450ms 切换一次，共循环 8 种表情；过渡持续约 500ms，以保持持续绘制
- 硬件：ESP32-D0WD-V3 / HW-950 ESP32-2432S024R，串口 COM7，屏幕 SPI 80MHz
- 运行时间：2026-10-08 20:43:03 至 20:45:56（Asia/Shanghai），约 2 分 53 秒
- 烧录：`pio run -e esp32dev_always_on_perf60_continuous -t upload --upload-port COM7` 成功，固件哈希校验通过

## 观测结果

| 指标 | 观测值 |
|---|---:|
| 稳态绘制窗口 | 25 个，每个约 5 秒 |
| 稳态绘制帧数 | 7,825 帧（每窗口 313 帧） |
| 稳态绘制频率 | 所有窗口约 62.5fps |
| 平均绘制耗时 | 各窗口 2.481–2.766ms |
| 稳态窗口内最大绘制耗时 | 4.327ms |
| 绘制超出 16ms 目标的帧 | 0 |
| 主循环频率 | 所有已采样窗口约 62.5fps |
| 主循环最大间隔 / 晚帧 | 16ms / 0 |
| 运行堆内存 | 249,164 bytes，采样中保持不变 |
| 芯片温度 | 4 次采样为 32.8–33.3°C |
| 运行中重启 | 未观察到 |

启动阶段单独出现过一个 5 秒窗口：308 帧、平均绘制频率约 61.5fps，最大绘制耗时 18.831ms，并有 1 帧超过 16ms。该窗口包含首次全屏绘制；其后的 25 个稳态窗口均没有超预算帧。

## 结论与边界

在这段短时、连续表情过渡负载下，程序测得的绘制频率和主循环频率稳定在约 62.5fps，16ms 压力目标下稳态没有晚帧或超预算帧。

本次只运行约 2 分 53 秒，因此不能据此证明数十分钟或数小时的热稳定性、长期内存稳定性。屏幕没有可读取的垂直同步反馈；日志测量的是固件循环与绘制调用频率，不代表用仪器测得的面板物理刷新率。
