# 连续动画 60fps：160MHz 短测记录

> 历史验证记录 · 2026-10-08。本报告中的 160MHz 临时性能环境已撤销；当前仅保留 `esp32dev_expression_test`，它使用 240MHz。以下结果仅适用于报告中的短时测试条件，不代表当前固件档位。当前参数见[技术文档](../技术文档.md)。

## 测试条件

- PlatformIO 环境：`esp32dev_always_on_perf60_continuous_160mhz`
- 硬件：ESP32-D0WD-V3 / HW-950 ESP32-2432S024R，COM7
- 屏幕 SPI：80MHz；帧间隔：16ms；每 450ms 切换表情，循环 8 种表情
- 烧录命令：`pio run -e esp32dev_always_on_perf60_continuous_160mhz -t upload --upload-port COM7`
- 烧录结果：成功，固件哈希校验通过
- 启动串口日志确认：`[POWER] cpu=160MHz`
- 本次为短时验证，未做长时间浸泡

## 结果

| 指标 | 启动窗口 | 稳态窗口 |
|---|---:|---:|
| 采样窗口数 | 1 | 24 个，每个约 5 秒 |
| 绘制帧数 | 306 | 7,512（313 帧/窗口） |
| 绘制频率 | 61.1fps | 所有窗口约 62.5fps |
| 平均绘制耗时 | 3.004ms | 各窗口 3.027–3.367ms |
| 最大绘制耗时 | 19.377ms | 峰值 5.065ms |
| 超过 16ms 的绘制帧 | 1 | 0 |

稳态主循环 24 个窗口均约 62.5fps，最大循环间隔 16ms，晚帧为 0。运行堆内存保持 249,164 bytes；4 次温度采样均为 32.2°C；没有观察到额外重启。

启动窗口包含首次全屏绘制，单独出现一次 19.377ms 峰值。后续稳态连续动画没有超过 16ms 的绘制帧。

## 结论边界

实测确认 CPU 实际处于 160MHz 时，连续动画短测仍能维持约 62.5 次/秒的程序绘制和主循环频率，满足当前 60fps 压力目标。测试只有约两分钟，不能据此判断长时间热稳定性。日志统计的是固件绘制调用，不是面板物理刷新率。
