# 历史验证记录

这些报告保留了不同临时调试固件和短时运行条件下的原始观测值。相关临时 PlatformIO 环境已从 2.0.0 配置中移除；报告中的数值不应当作当前三个正式固件档位的规格，也不能说明整机电流、续航或面板物理刷新率。

当前正式配置和说明：

- 三种固件环境、CPU 频率和程序帧周期见[技术文档](../技术文档.md)及[根目录 README](../../README.md)。
- 电池电压、电流和续航的测量边界见[电池供电诊断](../电池供电诊断.md)。
